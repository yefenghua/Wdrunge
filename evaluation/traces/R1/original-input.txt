# R1：基础留言板与简单样式

请基于现有 React、TypeScript、FastAPI 工程开发通过电脑浏览器访问的中文留言板 Web 网站，使用 SQLite 保存数据。启动本地前后端后，通过 HTTP 地址访问网页，不开发或打包客户端。

页面有昵称、留言内容、发布按钮和留言列表。昵称与内容去除首尾空格后不能为空，前后端均校验。发布后清空内容框并更新列表，显示昵称和内容，支持单独删除；空列表显示“暂无留言”。刷新及重启后端后数据保留。

标题为“访客留言板”，蓝色按钮、浅灰背景、白色留言卡片，单栏即可。提供几行启动说明和检查结果。

验收：
1. 构建、启动及网页访问成功，发布、显示、删除和简单样式正确。
2. 空白输入被拒绝，刷新及重启后数据保留，启动说明可用。

仅完成本次需求，沿用现有依赖，说明保持简短。电脑浏览器尺寸 1440×900；无需手机适配、搜索、分类或编辑。单次总预算 30 分钟，最多正式返工 1 次。
